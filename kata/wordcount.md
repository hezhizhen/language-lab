# Word Count

统计文本中每个单词的出现次数。

## 输入与输出

- 输入：一段字符串。
- 输出：单词到出现次数的映射，不要求键的顺序。

## 规则

1. 单词是由一个或多个连续的 ASCII 英文字母（A–Z、a–z）组成的片段。
2. 忽略大小写，输出中的单词统一为小写。
3. 所有非 ASCII 英文字母都视为分隔符，包括空白、标点、数字和非 ASCII 字符。
4. 连续、开头或结尾的分隔符不产生空单词。
5. 空字符串或仅包含分隔符的字符串返回空映射。

本题使用简化的分词规则，不进行自然语言分词。例如，don't 拆分为 don 和 t，café 中的 é 是分隔符。

## 示例

输出使用 JSON 对象展示，各语言可使用对应的映射类型。

| 输入                                | 输出                           |
| ----------------------------------- | ------------------------------ |
| `""`                                | `{}`                           |
| `" ,.!? \t\n"`                      | `{}`                           |
| `"word"`                            | `{"word": 1}`                  |
| `"Hello, Go! hello"`                | `{"hello": 2, "go": 1}`        |
| `"Go GO go gO"`                     | `{"go": 4}`                    |
| `"  hello,,,   world\n\n\thello  "` | `{"hello": 2, "world": 1}`     |
| `"abc123def 456"`                   | `{"abc": 1, "def": 1}`         |
| `"don't"`                           | `{"don": 1, "t": 1}`           |
| `"café 你好 naïve"`                 | `{"caf": 1, "na": 1, "ve": 1}` |

示例中的 \t 和 \n 分别表示制表符和换行符。

## 完成标准

- 实现符合上述规则。
- 自动化测试覆盖空输入、分隔符、重复单词、大小写，以及数字、撇号和非 ASCII 字符等边界情况。
- 测试全部通过。

不要求实现命令行界面、文件读取或结果排序。
